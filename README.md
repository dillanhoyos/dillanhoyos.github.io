# Dillan Hoyos - Audio Engineer & Editor Portfolio

Professional portfolio website showcasing audio engineering, sound design, and audio post-production work.

## About

This is a single-page portfolio website for Dillan Hoyos, an audio engineer and editor with 3+ years of professional experience. The portfolio demonstrates expertise in:

- Audio Editing & Mixing
- Sound Design
- Audio Post-Production for Video
- Game Audio Implementation
- Spatial Audio for VR/AR
- Technical Audio Programming

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Performance Optimized**: Lazy-loading videos, preconnected resources, and optimized CSS
- **SEO Enhanced**: Structured data, Open Graph tags, and semantic HTML
- **Accessibility**: ARIA labels, keyboard navigation, and focus states
- **Professional Showcase**: Video reels, project highlights, and comprehensive experience overview

## Sections

1. **Hero/Header**: Dynamic introduction with rotating specializations
2. **Sound Design Reel**: Featured demo reel showcasing professional work
3. **Games & Audio Implementation**: Interactive projects with detailed descriptions
4. **About**: Comprehensive background, experience, skills, and achievements
5. **Technical Guides**: Educational content demonstrating expertise
6. **Contact**: Direct contact information and social media links
